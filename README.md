# BizTextMaker

## 概要

BizTextMakerは、ビジネス文書を簡単に作成し、
プレビュー・印刷・PDF保存までをスムーズに行えることを目的として開発したWebアプリケーションです。

実務で行っていた文書作成業務をもとに、
「誰でも直感的に操作できるシンプルな画面」と
「必要最低限の操作で文書を作成できること」を重視して制作しました。

初学者として制作したためシンプルな構成ですが、
実際の業務で使うことを意識しながら設計・実装を行いました。

---

## 制作目的

実務ではExcelやWordを複数使用し、
文書ごとに編集やデータの同期が必要になるため、
作業手順が複雑になりやすいという課題がありました。

また、担当者が変わる際には、
操作方法をまとめた手順書が必要になることも多くありました。

そこで、

- 必要事項を入力するだけで文書を作成できる
- 誰でも迷わず操作できる
- 引き継ぎがしやすい

という3点を目標としてBizTextMakerを制作しました。

---

## 主な機能

- ログイン画面
- 発行日入力（NOWボタン対応）
- 文書テンプレート切替
- 顧客登録・編集・削除
- 顧客一覧の五十音順表示
- 顧客選択（datalist）
- 入力チェック
- 備考入力
- 文書プレビュー
- 印刷
- PDF保存

## 制作を通して学んだこと

今回の制作では、機能を追加するだけではなく、
コードの整理や保守性を意識する重要性を学びました。

特に、

- HTML・CSSの役割分担
- JavaScriptの処理の流れ
- ファイル構成
- コードの可読性
- GitHubによるバージョン管理

について理解を深めることができました。

また、動作するコードを書くことだけでなく、
後から読みやすく修正しやすいコードを書くことの大切さを実感しました。
